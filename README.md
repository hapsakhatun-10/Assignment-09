# PetHome — Frontend

A pet adoption platform built with Next.js. Browse pets, submit adoption requests, and manage your listings.

## Live URL

https://assignment-09-a6sk.vercel.app/

## Features

- Browse and search pets by species and keyword
- Pet detail pages with full info, images, and shelter details
- User authentication via email/password and Google OAuth
- Submit and manage adoption requests
- Dashboard for pet owners to manage listings and track requests
- Add, edit, and delete pet listings with shelter information
- Request approval/rejection workflow for pet owners

## NPM Packages Used

### Dependencies
- **next** — React framework with file-based routing
- **react / react-dom** — UI library
- **better-auth / @better-auth/mongo-adapter** — Authentication (email + Google OAuth)
- **@heroui/react / @heroui/styles** — UI component library
- **lucide-react** — Icon library
- **react-icons** — Additional icon library
- **@gravity-ui/icons** — Icon library
- **@iconify/react** — Universal icon framework
- **react-hot-toast** — Toast notifications
- **mongodb** — MongoDB database driver

### Dev Dependencies
- **tailwindcss / @tailwindcss/postcss** — Utility-first CSS framework
- **eslint / eslint-config-next** — Linting
- **babel-plugin-react-compiler** — React compiler
